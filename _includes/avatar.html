{%- comment -%} Profile avatar. Shows a photo if one exists, otherwise a placeholder icon. Params: name - person's English name (used for alt text + auto filename) photo - optional: override filename inside /assets/img/people/ (e.g. "custom.png") Photo filename convention (when `photo` is not given): English name -> lowercase -> spaces replaced with "-" -> add ".jpg" e.g. "Sueon Chae" -> assets/img/people/sueon-chae.jpg {%- endcomment -%} {%- if include.photo and include.photo != "" -%} {%- assign imgfile = include.photo -%} {%- else -%} {%- assign imgfile = include.name | downcase | replace: " ", "-" | append: ".jpg" -%} {%- endif -%}
